# Job Agent

Finds data science, ML and AI jobs (internships and full-time), ranks them against what you're looking for, prepares a tailored one- or two-page resume and truthful answers for each application, and submits only the ones you approve. It respects per-company application limits and works with Greenhouse, Lever, Ashby and Workday.

## How to use it

1. **Resumes:** upload your resume PDF(s), review the merged master resume, and accept it. Your profile is filled in from it.
2. **Search:** describe the jobs you want, set filters and the fit threshold, and save.
3. **Today:** refresh the job lists. Then rank them on **Ranked jobs**.
4. **Prepare top matches**, then review each one in the **Approval queue**. Edit answers, approve, and submit.
5. **Applications:** optionally import your job-tracking CSV, and record outcomes.

Sessions last about 30 minutes and keep nothing afterwards. Use **Download everything** in the banner before the session ends. Workday passwords created in a session appear on the Applications page.
