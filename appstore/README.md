# Job Agent

Finds jobs in the fields you choose (internships to senior roles), ranks them against what you're looking for, prepares a tailored one- or two-page resume and truthful answers for each application, and submits only the ones you approve. It discovers companies on the job sites they hire through, counts each job once even when it's posted on several boards, and skips jobs you've already applied to. It works with Greenhouse, Lever, Ashby and Workday, and fills other sites with a browser agent.

## How to use it

1. **Resumes:** upload your resume PDF(s), review the merged master resume, and accept it. Your profile is filled in from it, and you can edit both at any time.
2. **Search:** describe the jobs you want, pick your fields, set filters and the fit threshold, and save.
3. **Today:** refresh the job lists, or **Discover companies**. Then rank them on **Ranked jobs**.
4. **Prepare top matches**, then review each one in the **Approval queue**. Edit answers, approve, and submit.
5. **Applications:** optionally import your job-tracking CSV, and record outcomes.

Or use the **Assistant** tab: ask in plain words ("find my 3 best matches and prepare them", "add my new project to my resume", "make this cover letter shorter"). It uses the same tools, shows each step, and can only *ask* to submit: nothing is sent until you click.

Sessions last about 30 minutes and keep nothing afterwards. Use **Download everything** in the banner before the session ends. The platform allows about 20 model requests per visit, so each assistant reply uses a few and ranking scores only the best keyword matches. Workday passwords created in a session appear on the Applications page.
